# Business & Technology Portfolio

A responsive professional portfolio for Saudi recruiters and employers. It presents five interactive business applications spanning research analytics, corporate operations, CRM, procurement, and budget monitoring.

The portfolio accurately describes the applications as AI-assisted development work completed with Codex. All project records are fictional, synthetic, or simulated; they are not client deployments or evidence of real commercial outcomes.

## Technology

React, TypeScript, Vite, and plain responsive CSS. The site has no backend, database, authentication, external API, or paid service.

## Local development

```bash
npm install
npm run dev
```

Verification and production build:

```bash
npm test
npm run build
```

## GitHub Pages

Vite uses a relative `./` base so built assets work below a GitHub repository subpath. Build with `npm run build` and publish the generated `dist` directory through GitHub Pages. The planned repository name is `saudi-professional-portfolio`; no repository or deployment is created as part of this implementation.
